# Demo Arena

A tiny arena collector: gather the stars, dodge the hazards, beat the clock.

This is a **grey-box skeleton** generated by Weaverbird from the
approved scope in `../SCOPE.md`. It is a real, playable Godot 4
project — the whole loop works — but everything visual is a
placeholder shape drawn in code. Later factory stages replace the
drawings with real assets and grow the gameplay; they do not need to
rewire the menus, save system or scene flow, which are finished
here.

## How to play

- **Move:** WASD or the arrow keys
- **Pause:** Esc or P (Resume / Restart / Main menu)
- **Interact:** E or Space (defined for later stages; the grey-box
  loop does not need it)

## The grey-box rules

- One bounded arena. You are the coloured disc; your colour and the
  target colour come from the scope's style lock when it names hex
  colours, and are neutral otherwise.
- Collect every target disc before the round timer runs out to win.
  The round lasts 75 seconds — the scope's session
  length (5 minutes), scaled down to grey-box size.
- Touch a red square hazard and the run is lost. Let the timer reach
  zero and the run is lost.
- There are 3 targets, from the scope's content
  counts when it names a number.

## What is wired and working

- Main menu (title and pitch from the scope) with Play / Settings /
  Quit, and your saved stats: games played, wins, best targets.
- Settings screen with a volume slider, saved to `user://` the
  moment it moves.
- Pause overlay, win screen and game-over screen, and the flow
  menu → game → win/lose → menu.
- Save/load: settings and run stats persist as JSON in `user://`
  (`scripts/settings_store.gd`).

## What is placeholder

- All art: the player, targets and hazards are shapes drawn in code
  (`scripts/player.gd`, `scripts/marker.gd`), and `icon.svg` is a
  simple generated placeholder.
- The gameplay itself is the generic grey-box loop above — the
  scope's real mechanics are built in later stages.
- There is no music or sound yet; the volume slider drives the
  master bus ready for when audio arrives.

## Checking it works

A headless smoke run that plays menu → game → win by itself ships
in `smoke/smoke.gd`:

```
godot --headless --path . --script smoke/smoke.gd
```

It prints `SMOKE PASS` and exits 0 when the loop works. Weaverbird
ran it — plus an import pass and plain runs of the menu and game
scenes — when this skeleton was generated; the results are in
`../.weaverbird/skeleton_report.json`.
